# 内容同步授权：受控操作

`ainpe-authorize.service` 是一次性、仅手动启动的授权服务，不绑定定时器，不自动重启，也不会自动打开浏览器。它以 `ainpe` 身份运行，只能写入既有的私有授权目录；20 分钟没有完成会自行失败，systemd 在 22 分钟时兜底终止。此服务独立于 SSH 会话，单次连接中断不会立即销毁正在等待的流程，但超时后不能恢复旧流程。

操作前确认已部署并核验该版本、私有目录权限正常、没有已有有效授权或正在进行的授权。安装 unit、重新加载 systemd 并受控启动一次；检查 systemd 状态和单次服务日志中严格限定的 `AUTHORIZATION_READY`、`AUTHORIZATION_SUCCEEDED`、`AUTHORIZATION_NOT_COMPLETED` 或 `ALREADY_AUTHENTICATED` 标记。不要输出服务日志中的其他内容，不记录浏览器地址、回调参数或凭据。就绪标记不是成功标记；只有完成标记与服务正常退出同时出现，才能确认此次授权成功。

本机 SSH 转发独立运行并保持在前台，使用 `ExitOnForwardFailure=yes`、`ServerAliveInterval=20`、`ServerAliveCountMax=6`，同时严格绑定本机回环地址。启动后用不触发授权的无效路径进行一次本机到服务的连通检查；确认服务仍处于就绪后才打开用户浏览器。若 SSH 中断而服务仍在等待，可重建同一个转发连接，保持原流程等待；不要再次访问一次性启动入口或创建另一流程。进程结束、超时或授权失败时，停止转发并保留上次同步内容，等待另行决定是否重试。

仅在一次授权成功、凭据已安全保存、首次同步及归档均成功后，才考虑启用每日同步计时器；单独核对该计时器状态。此文档本身不启动任何服务。
